Lab 6: Hometown Map

My Nashville Map

This interactive map highlights 10 of my favorite places in Nashville, Tennessee. Click on any marker to see the location name, a photo, and why it's meaningful to me. You can zoom in and out and pan around the map.

About This Project

For this lab, I built an interactive map of my hometown using Python, Folium, and the Mapbox API. I created a CSV file of 10 meaningful locations in Nashville — including parks, restaurants, music venues, and more — and wrote a Python script to geocode each address and plot them on a custom-styled Mapbox basemap.

Each marker is color-coded by location type and includes a popup with the place name, my personal description, and a photo. The map was generated as an HTML file and embedded into this page.

Tools Used

  • Python — scripting and data processing
  • Folium — generating the interactive Leaflet map
  • Pandas — reading and managing the CSV data
  • Mapbox Geocoding API — converting addresses to coordinates
  • Mapbox Studio — custom map style

What I Learned

This project taught me how to use APIs to geocode real-world addresses, how to create interactive web maps with Python, and how to style and customize map tiles using Mapbox Studio. I also learned how to embed generated HTML files into a larger website layout.
