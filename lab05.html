Lab 5

Introduction

In this lab, I used AI assistance to help build and understand features on my portfolio website. I explored how to work effectively with AI tools while maintaining my own understanding of the code. This included the dark mode toggle functionality and the carousel slider for displaying my lab work.

What I Built/Analyzed

I developed two main features for my portfolio with AI assistance:

1. Dark Mode Toggle

A responsive toggle switch that allows users to switch between light and dark color schemes. The implementation uses CSS custom properties (variables) to manage color changes and localStorage to save user preferences.

2. Carousel Slider

An interactive carousel that showcases my lab assignments one at a time with navigation arrows and dot indicators. Each slide displays a lab image, title, description, and link to the full lab.

Vibe Coding Guidelines

Through this lab, I developed the following personal coding practices:

  • Understand Before You Copy: Even when AI generates code, I take time to understand what each line does. I added comments explaining the logic in my own words.
  • Accessibility Matters: I pay attention to features like aria-labels and aria-expanded attributes that make my site usable for everyone, not just those with perfect vision.
  • User Preferences: I save user choices (like dark mode preference) to localStorage so their experience is personalized across visits.
  • Responsive Design: Features should work on both desktop and mobile. I use CSS to adapt button sizes and layouts for smaller screens.
  • Meaningful Comments: Comments should explain the "why" not just the "what." What did I struggle with? What surprised me?
  • Test Incrementally: Instead of building everything at once, I tested each feature (dark mode, then carousel) to catch problems early.

Key Takeaways

This lab taught me that AI is a tool for acceleration, not a replacement for understanding. I can use AI to help generate code, but I need to take responsibility for comprehending it, testing it, and making sure it aligns with my accessibility and design standards. The features I built enhance my portfolio's user experience while teaching me valuable lessons about interactive web design.
