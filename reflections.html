Lab Reflections

Lab 2 – AI Experimentation

This lab focused on experimenting with different AI tools and thinking critically about how they work. I tested multiple AI platforms and compared their responses to different prompts. The goal was to understand both the strengths and limitations of AI and how it can be used responsibly in academic and professional work. This lab also involved documenting my findings and adding them to my portfolio site.

Tools / Skills: AI tools (ChatGPT, Gemini, etc.), prompt writing, evaluating AI responses, ethical AI use

Lab 3 – Visualization Critique

In this lab I analyzed an existing data visualization using ideas from Edward Tufte about what makes a good visual explanation. I chose a visualization and wrote a critique explaining what worked well and what could be improved. This assignment helped me think more carefully about how data is presented and how visual design choices can affect how people interpret information.

Tools / Skills: Data visualization critique, design principles, visual communication analysis, page design

Lab 4 – Tableau Visualization

For this lab I worked with Tableau Public to create a data visualization using a dataset. I explored the data to see what patterns or trends appeared and then designed a visualization to show those findings. After creating the chart in Tableau, I embedded the interactive visualization into my portfolio site. This lab helped me get more comfortable with exploratory data analysis and visual storytelling.

Tools / Skills: Tableau Public, data exploration, visualization design, embedding interactive graphics in HTML

Lab 5 – Vibe Coding with AI

This lab explored the idea of "vibe coding," which is basically using AI tools to help generate and troubleshoot code. I experimented with AI coding assistants and learned how they can speed up development but still require human oversight. The goal was not just to generate code, but to understand what the code was doing and how to modify it.

Tools / Skills: AI coding tools (GitHub Copilot), debugging, editing AI-generated code, GitHub

Lab 6 – Interactive Mapping Project

In this lab I created an interactive hometown map that highlighted locations that are personally meaningful to me. I designed a custom basemap in Mapbox Studio and then used Python to generate an interactive map with markers and pop-ups for each location. The project combined design, data, and coding, and helped me understand how geographic data can be turned into interactive visual experiences.

Tools / Skills: Mapbox Studio, Python, Folium, geocoding, CSV data creation, interactive mapping
