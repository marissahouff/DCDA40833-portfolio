Semester Reflection

Before starting these labs, tools like VS Code and GitHub were completely new to me, so at first the whole process felt a little intimidating. However, the step-by-step guidance throughout the labs made it much easier to follow along and gradually build confidence. Lab 1 especially helped set the foundation because it walked me through creating my portfolio site and understanding how GitHub, VS Code, and GitHub Pages all work together.

As the labs continued, I learned how to use a variety of digital tools and think more critically about technology and data. In Lab 2, I experimented with different AI tools and started thinking more about how AI can be used responsibly while also understanding its limitations. Lab 3 helped me analyze data visualizations more closely by applying Edward Tufte's design principles and thinking about how visuals influence the way information is interpreted. In Lab 4, I worked with Tableau Public for the first time and learned how to explore datasets, create visualizations, and embed interactive graphics directly into my website.

Lab 5 introduced the idea of "vibe coding," where AI tools can help generate or troubleshoot code. This lab helped me understand how AI can act as a collaborator in coding while still requiring me to understand and adjust the code myself. Finally, Lab 6 brought together many of the skills I had been building by having me create an interactive hometown map. I used Mapbox Studio to design a custom basemap and Python to generate an interactive map with markers and pop-ups for meaningful locations.

One of the biggest challenges for me throughout the semester was figuring out where content belonged in the different files and understanding how everything connected behind the scenes. Over time, though, navigating between HTML files, styles, and embedded tools became much more natural. Overall, these labs helped me gain a much better understanding of how digital tools work together, from coding and AI to data visualization and mapping,and I feel a lot more confident using these technologies moving forward.
